Farever Plugin API — Complete Documented Function List
=======================================================

Source: installed Farever plugin API reference
Includes farever.*, imgui.*, lifecycle callbacks, event names, and returned
record fields. The removed farever.foes.* API is intentionally excluded.

Do not call imgui.begin() or imgui.end(); Farever manages the plugin window.


EVENTS DELIVERED TO on_event(name, data)
----------------------------------------
hero_locked
  data: empty

fight_start
  data: { fight_id }

damage_dealt
  data: { skill, amount, is_crit, is_kill, target, blocked }

heal_dealt
  data: { skill, amount, is_crit, target }

shield_applied
  data: { skill, amount }

fight_end
  data: { fight_id, duration, total_damage, dps, top_skill }

target_changed
  data: { kind }

cast_start
  data: { skill, total_sec }

cast_end
  data: { skill, duration }

weapon_changed
  data: { kind, prev_kind, level, upgrade }


REMOVED / UNAVAILABLE API
-------------------------
farever.foes.*
  Removed because the multi-foe tracker caused game crashes. The supported
  replacement is farever.target.*, which tracks only the current target.
